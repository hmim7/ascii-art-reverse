DESCRIPTION:
Implement main.go as a thin orchestrator: ≤ 60 lines, no business logic.
Calls ClassifyArgs once, dispatches to the correct pipeline (reverse, stdin,
or render), and handles top-level errors. All string output is delegated to
errs.go; all I/O is delegated to output/; all rendering to render/.
main.go imports from all five internal packages but contains zero flag-parsing
or rendering logic of its own.

REQUIREMENTS:
- package main; imports: cli, banner, output, render, reverse (all internal/)
- Call cli.ClassifyArgs(os.Args[1:]) once
- Emit cli.Fatal(cli.SelectUsage(args)) if unknownFlags or malformed with no valid flags
- Call cli.EmitWarnings(args) for warnings alongside valid flags
- Resolve banner name from args.Positional (default "standard")
- Call banner.Load(bannerName); handle error with os.Exit(1)
- Reverse branch: reverse.Run → fmt.Println → return
- Output branch: output.GetWriter(args.OutputValue); defer file.Close()
- Input: args.Positional[0] or cli.ReadStdin() if StdinMode
- segments := render.ParseInput(input)
- Gopher check: render.ShouldRenderGopher → render.RenderGopher → return
- rules := cli.BuildColorRules(args.ColorRules)
- width := render.ResolveWidth(args.OutputValue != "")
- render.RenderAlignedWithColorRules(writer, segments, bannerMap, rules, align, width)
- Hard limit: ≤ 60 lines including package declaration and imports
- No external packages — standard library only
- Requires: ALL previous tasks complete
