TITLE: Reverse Feature (ASCII Art → Text)
ROLE: Reverse Engineering
STATUS: TODO

DESCRIPTION:
Implement internal/reverse/reverser.go. Reads a file containing ASCII art
(generated by this program or a compatible tool), reconstructs the original
plain-text string, and prints it. Uses a reverse lookup map built from the
banner map and a greedy left-to-right column scanner to identify each character.

REQUIREMENTS:
- Run(filePath string, bannerMap map[rune][]string) (string, error)
    reads file → strips trailing blank lines → groups into 8-line blocks
    (rows separated by a single blank line = multi-line source input)
    reconstructs each row → joins with \n → returns final string
- buildReverseMap(bannerMap map[rune][]string) map[string]rune
    signature = strings.Join(8 art lines, "|")
    inverts bannerMap: signature → rune
- matchSegment(lines []string, rev map[string]rune, widths []int) (string, error)
    greedy left-to-right scan at each column offset
    tries all known glyph widths; first match consumed
    returns reconstructed string for this 8-line block
- Default banner for reverse: standard (unless positional arg overrides in main)
- Flag format: --reverse=<fileName> (space version caught by ClassifyArgs → Malformed)
- No external packages — standard library only
- Requires: TASK 04 complete (banner map), TASK 08 complete (render types)

FILES TO CREATE/MODIFY:

- internal/reverse/reverser_test.go
