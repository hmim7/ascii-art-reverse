TITLE: Peeking Gopher Easter Egg
ROLE: Render Engineering
STATUS: TODO

DESCRIPTION:
Implement internal/render/gopher.go. Triggered when the input is 100%
non-ASCII (nothing renderable after filterASCII). Instead of silently
producing empty output, the program renders a hardcoded ANSI Peeking Gopher
art to the writer and exits 0. This applies in both color and normal mode.

REQUIREMENTS:
- ShouldRenderGopher(text string, segments []string) bool:
    true when: text != "" AND containsNonASCII(text) AND every segment is blank
- containsNonASCII(text string) bool:
    skip \n, \t, \\ when checking
    any rune < 32 or > 126 (excluding those three) counts as non-ASCII
- RenderGopher(w io.Writer): writes hardcoded multi-line ANSI art string
- Gopher check runs before the render pipeline in main.go
- Exit code 0 on gopher render (success path)
- No external packages — standard library only
- Requires: TASK 05 complete (filterASCII used by segments check)

FILES TO CREATE/MODIFY:
- internal/render/gopher.go
- internal/render/render_test.go (extend)

ACCEPTANCE CRITERIA / TEST CASES:

- [CLI]: go run . "héllo" → "llo" renderable → NO gopher (mixed input)
- [CLI]: go run . "" → empty string, no gopher (text == "")
- [CLI]: go run . "𝕳𝖊𝖑𝖑𝖔" → all non-ASCII → gopher rendered
